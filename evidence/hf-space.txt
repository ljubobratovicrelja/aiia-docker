What this file is
-----------------
The assignment's last max-grade bullet is "Upload to Hugging Face spaces and use of
online API inference". This artifact is the proof of the second half: a call to the
*public* Space API from outside, with no local model, no local GPU and no container,
plus the runtime facts (stage, hardware) read back from the Hub.

Regenerate with
---------------
  export HF_TOKEN=<a token that can read the Space's runtime>   # optional, for metadata
  python3 scripts/verify_hf_space.py --max-new-tokens 200

What is being served
--------------------
  model    : ljubobratovicrelja/qwen3.5-2b-magicoder-lora  (merged text-only, bf16, 3.76 GB)
  app      : space/app.py  — the model loads at Space start (outside @spaces.GPU, where
             CUDA is emulated, so the load costs no ZeroGPU quota) and generation runs
             inside @spaces.GPU(duration=30)
  sampler  : the Qwen3.5 card's non-thinking text set, reproduced exactly — including
             presence_penalty=2.0 as a hand-rolled LogitsProcessor, because transformers
             5.20 dropped the parameter and llama.cpp applied it in the benchmark
  hardware : ZeroGPU (zero-a10g) — a PRO account's 40 GPU-min/day, 10 ZeroGPU Spaces

Deployment notes worth keeping (all of them cost a cycle to learn)
------------------------------------------------------------------
* The Hub's free tier no longer covers compute Spaces at all: creating a Gradio or Docker
  Space on cpu-basic returns 402, and so does ZeroGPU without PRO. The model repo is
  free and needs none of this; only the *serving* half is paid.
* Gradio 6 serves the app config at `/config`, NOT `/gradio_api/config` (the
  `/gradio_api` prefix applies to the call endpoints); the endpoint signatures are at
  `/gradio_api/info`.
* `gr.ChatInterface(examples=[...])` must be given a list of LISTS when
  `additional_inputs` is used — a flat list raises at construction time and the Space
  dies in RUNTIME_ERROR with the traceback in the run log.
* The run log shows ZeroGPU packing the 3.76 GB of tensors ("ZeroGPU tensors packing")
  right before the app starts; the model download itself was fast (~300 MB/s).

Hypothesis: 'RUN pip install --no-cache-dir -r requirements.txt' could be
simplified to 'RUN pip install -r requirements.txt'.  Both variants were
built here from the identical context so the difference is only the flag.

  variant A (kept)    : gui/Dockerfile unchanged — pip install --no-cache-dir
  variant B (rejected): same Dockerfile with '--no-cache-dir' removed from the pip install

Generated variant B Dockerfile:
    FROM python:3.12-slim
    
    WORKDIR /app
    
    # Dependencies first, app code last: editing app.py must not reinstall gradio.
    COPY requirements.txt .
    RUN pip install -r requirements.txt
    
    COPY app.py .
    
    EXPOSE 7860
    
    CMD ["python", "app.py"]

  once at build time.  gui/Dockerfile is left exactly as committed; the
  experiment images are removed, and aiia-docker/gui:stage-1

CROSS-CHECK — the same two images measured a second way
======================================================================

Added after the run above, on the same two images (rebuilt from cache so they
are the same layers).  On this engine `docker image inspect .Size` adds the
compressed layer sizes to the uncompressed ones, so a size DELTA read off
.Size is inflated by the same double count: 177.4 MB here, against 84.1 MB
measured on the aarch64 host where .Size did not double count.  The honest
delta is the difference in file bytes:

  image	layers	blob_bytes	files_bytes	history_sum	.Size	history+blob	residual
  aiia-docker/gui:pip-nocache-experiment	8	151671271	441747285	491079190	642651093	642750461	-99368
  aiia-docker/gui:pip-cache-experiment	8	237817686	529711073	582079190	820039989	819896876	143113

  delta, file bytes     (B - A) : +87,963,788 B   (+88.0 MB, +19.9%)
  delta, compressed     (B - A) : +86,146,415 B   (+86.1 MB)
  delta, history sum    (B - A) : +91,000,000 B   (+91.0 MB)
  delta, docker .Size   (B - A) : +177,388,896 B   (+177.4 MB)  <- the inflated one

  where the extra bytes are, inside variant B's image:
    88M	/root/.cache/pip
  and inside variant A (the kept one):
    no pip cache dir: --no-cache-dir leaves nothing behind

  Conclusion unchanged, number corrected: dropping --no-cache-dir costs
  ~84 MB of real image (the wheels pip would never reuse, since the install
  happens once at build time), not the 177 MB the double-counted .Size
  suggests.  Keeping the flag is right; the delta worth quoting is the file-
  byte one.

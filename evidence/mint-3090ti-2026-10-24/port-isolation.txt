======================================================================
What this shows, and what it does not
======================================================================
* inference has no 'ports:' key on either stack, so Compose creates no host
  binding for it: HostConfig.PortBindings is the empty map {} and NetworkSettings.Ports
  shows the port as exposed-but-unpublished ("8080/tcp": null).  That is why
  every CPU and GPU benchmark call is made from inside the compose network
  with 'docker compose exec -T inference curl'.
* gui publishes 7860 on 0.0.0.0 and ::, so 'ss' shows exactly the gradio
  sockets for this stack and nothing else — one published port, by design.
* The GPU override does not touch gui and does not add a ports: mapping to
  inference: the isolation survives the override.  Checked here, not asserted.

End state of the machine after this capture: the GPU stack is up.

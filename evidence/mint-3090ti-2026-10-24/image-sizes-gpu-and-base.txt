The project script (evidence/mint-3090ti-2026-10-24/image-sizes.txt) covers the
cpu target and the gui.  This file covers the two things it does not: the gpu
target and both upstream llama.cpp base images, in the same byte-exact form.

READ WITH: image-sizes-reconciliation.txt, which measures the same five images
four different ways.  Short version: on this engine `docker image inspect
.Size` adds each layer's compressed size to its uncompressed size, so .Size
(9.02GB for the gpu image) is NOT the image's footprint (5.37GB of files).
Both are printed below; the reconciliation file proves the identity.
